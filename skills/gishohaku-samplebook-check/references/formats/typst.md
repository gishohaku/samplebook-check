# Typst の奥付

## 仕組み

Typst にも奥付の標準機能はない。テンプレート側で奥付用の関数（`colophon(...)` など）を定義し、本文の最後で呼び出す形が多い。
`#set document(title: ..., author: ...)` はPDFのメタデータで、ページには印字されないので奥付の項目としては数えない。

## 手順

1. `python scripts/check_source.py <プロジェクト> --format typst` を実行する
2. `colophon_candidates` のファイルを開く。奥付が関数呼び出しになっている場合は、引数の値（書名・著者・日付など）と、関数定義の両方を確認する（引数を受け取っても表示していないことがある）
3. 候補が見つからなければ、メインの `.typ` ファイルの末尾と、`#include` されている最後のファイルを読む
4. 最終確認はビルド済みPDFで行うよう案内する
