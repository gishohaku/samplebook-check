# 内容チェックの基準（技書博）

出典（最終更新時点の内容を要約）:
- 見本誌の提出 https://gishohaku.notion.site/samplebook-submissions （2025-11-06）
- サークル向け重要説明事項 https://gishohaku.notion.site/booth-important-explanation （2025-12-09）
- 行動規範 https://gishohaku.dev/code-of-conduct （v2.0.0, 2025-04-16）

## 1. このチェックの位置づけ

- 技書博は「社会通念上、誰が見ても問題ない」ことを重視し、**グレーゾーンも厳しく判断する**と明言している。セルフチェックでも、迷うものは「要確認」として挙げる側に倒す。
- ただし技書博は「著者が信念をもって解説できるものはすべて技術」としており、分野を制限しない。セキュリティ、化学、ハードウェアなど、扱いに注意が要る分野でも、技術解説そのものは歓迎される。問題になるのは**実害につながる具体的な手順**や、**違法行為・悪用への誘導**である。

## 2. 確認する場所

運営はテキスト（目次・各ページ）とイラスト（表紙・裏表紙・挿絵）の両方を確認する。

このスキルが判定するのは**テキストだけ**とする。画像の妥当性（露出の程度、構図、写り込みの権利など）は、画像を見ても判断が人によって大きく分かれ、スキルが「問題なし」と言うと誤った安心を与えるため。画像については判定せず、`self-review-checklist.md` の「A. 画像のセルフレビュー観点」を、画像を含むページの一覧（`scan_content.py` の `image_pages_text`）とあわせて提示し、著者自身に見直してもらう。

ただし、画像の中の文字（図中のテキスト、スクリーンショットの文面など）に、テキストと同じ基準で明らかな問題がある場合は、テキストの指摘として扱ってよい。

## 3. 確認項目

運営事務局の確認項目は次のとおり。レポートのカテゴリ名もこれに合わせる。

| カテゴリ | 内容 |
|---|---|
| 武器製造 | 武器・爆発物の製造に関する記載 |
| 麻薬製造 | 麻薬・違法薬物の製造に関する記載 |
| 毒劇物製造 | 毒物・劇物の製造に関する記載 |
| 自殺幇助 | 自殺を助ける・促す記載 |
| 知的財産権 | 第三者の知的財産権を**著しく**侵害していないか |
| 性表現 | 性表現、成人向け、性的なニュアンスを想起させるもの |
| 暴力・残虐表現 | 暴力表現、残虐表現、グロテスク表現 |
| 行動規範 | 行動規範に抵触する内容（差別、ハラスメント、個人情報の不正利用など） |
| 広報行為 | 企業制作物の頒布ルールに反する宣伝 |
| その他法令・公序良俗 | 上記以外で法律や公序良俗に反する記載 |

## 4. 法律・条例違反の例

武器・爆薬・毒劇物の製造方法をはじめ、刑法などに反するもの、犯罪の教唆と受け取れるものは頒布できない。公式が挙げる「頒布を許可しない本」の例を言い換えると次のような類型になる。

- 爆発物で建物を効率よく破壊する方法を解説するもの
- 脱税で資産を増やす方法を解説するもの
- 脱法ドラッグを作る方法を解説するもの
- 同意のない性的行為を推奨するような表現
- 各種法律の規制をすり抜けることを推奨するような表現

## 5. 公序良俗違反と、危険性のある技術の本

合法な行為でも、組み合わせることで違法行為・脱法行為を助長しうる手法の紹介は、頒布できない場合がある。公式の例は次の類型。

- 飲酒などを使って同意のない性的行為に持ち込む手法
- 個人情報の特定などによってストーキングにつながる手法

一方で、公式は「OSINTなどの技術解説自体を抑止するものではない」と明記している。悪用もできる技術（OSINT、セキュリティ診断、スクレイピング、追跡・監視技術など。以下「危険性のある技術」）の解説は、書き方しだいで頒布できる。

### 判定の基準

上から順に当てはめ、最初に当たったものを採用する。

| 本の書き方 | 判定 |
|---|---|
| 悪用を勧めている、悪用できると言い切って誘っている、違法行為・脱法行為を肯定・助長している | ❌ |
| 技術の解説であり、**「技術解説のみを目的とする」「悪用は強く拒否する（禁止する）」という趣旨の文言がある** | ✅ |
| 技術の解説だが、上の文言がない | ❌（まえがきへの追記が必須。追記すれば解消する） |

- 1行目の ❌ は書きぶりの問題なので、注意書きを足しても解消しない。該当する記述の削除や書き直しを求める。
- 3行目の ❌ は、文言を追記すれば解消する。レポートでは「追記をおすすめします」ではなく、**「まえがきに必ず追記してください」**と書き、そのまま使える文例を添える。
- 「悪用できると言い切る」とは、悪用を読者への利点として示すことを指す（例：「この方法なら、相手に気づかれずに何でも調べられます」）。危険性の説明として「悪用されうる」と書くことは当たらない。
- 文言は、まえがきにあること（別紙など、同じくらいわかりやすい場所でもよい）。本文の途中や章末にしかない場合は、まえがきへの追記を求める。`scan_content.py` の `dual_use_disclaimer` の `required_` の2点が目安になる。
- 公式は、こうした本に次の4項目の記載と、頒布時の口頭での説明を求める場合がある。`recommended_` の2点（違法行為を助長しない、成人に限る）が欠けていても判定は下げないが、4項目そろえた文例を示し、口頭説明の可能性も伝える。
  1. 本が技術解説のみを目的としていること
  2. 違法行為や脱法行為を助長するものではないこと
  3. 読者による悪用を禁止すること
  4. 購入者が成人であり、未成年には読ませないこと
- 危険性のある技術に当たらない一般的な技術書（Webアプリ開発で脆弱性対策に触れる程度など）には、この文言を求めない。

## 6. 全年齢の原則と、その例外

- 技書博は誰でも参加でき、子どもが本を手に取る可能性がある。**頒布物は全年齢向けが原則である。**
- 会場に年齢ゾーニングを導入する予定はない。性表現や暴力表現のために成人向けとしている本は、頒布できない。
- **例外：危険性のある技術（OSINTなど）を扱う本は、読者を成人に限定できる。** 5の4項目にあるとおり、公式自身が「未成年には読ませない」旨の記載を求める場合があるため。この場合の成人限定は、全年齢の原則への違反として扱わない。
- 本筋と無関係な性表現・暴力表現は、程度が軽くても指摘の対象にする。
- 冗談や比喩としての性的な表現（「〇〇プレイ」のような言い回しを含む）も、行動規範上は対象になる。
- キャラクターの描写や衣装も、文脈によっては不適切と見なされる（行動規範4）。画像はスキルでは判定しないので、セルフレビュー観点として著者に確認してもらう。

## 7. 企業制作物・広報宣伝物

企業またはその従業員が主体となって一般サークルとして出展する場合、技術解説が主の物品なら頒布できる。次のいずれかに当たると営利目的と判断され、頒布できない（協賛での参加が案内される）。

- **同じ企業による会社・製品などの説明が2ページを超える**
  - 1社が会社説明を3ページ → NG
  - 2社が各2ページずつ、計4ページ → OK
- 人材採用や広報宣伝を主目的にした資料
- プロダクト・サービスの宣伝を主目的にした資料
- 営利目的での製品の購入・利用を誘引する資料

非営利のOSSや技術コミュニティは対象外。広報宣伝物（チラシ等）は、非営利のイベント告知・コミュニティ紹介は可、企業の採用募集・サービス紹介や営利目的のイベント・コミュニティの宣伝は不可（スポンサー等を除く）。

スキルでの扱い:

- この規定の対象は、企業またはその従業員が主体となって出展する本である。個人サークルの本に著者自身の会社や勤務先の紹介が出てくる場合は、宣伝が主目的と読めるときだけ指摘する。
- `scan_content.py` の `promotion` ヒントと `company_mentions` を手がかりに、企業ごとに「会社・製品・採用の説明にあてられたページ」を数える。技術の説明の中で社名に触れるだけのページは数えない。
- 1社で2ページを超える場合は ❌。2ページ以内は ✅（ちょうど2ページなら「上限ちょうどです」と注記するだけにする）。
- ユーザーがスポンサーとして参加している場合は対象外になるので、その可能性を注記する。

## 8. 行動規範に関わる注意

公式が「とくに気をつけてほしい」としているのはハラスメント。他者を貶めたり人格を損なう記述すべてが対象で、**否定的なメッセージには十分注意**するよう求めている。ほかに次も行動規範で禁止されている。

- なりすまし
- 個人情報の不正利用（本人の同意のない氏名・連絡先・顔写真・SNSアカウント・発言などの掲載を含む）
- 反社会的勢力との関係、犯罪や暴力の肯定・助長
- 性別、性自認、性的指向、身体的特徴、障がい、年齢、人種、国籍、宗教、政治的信条、職業などに関する差別的な表現

特定の個人・企業・製品を名指しで強く攻撃する記述、他人のSNS投稿やスクリーンショットを同意なく晒す記述は ⚠️ 以上で挙げる。技術的な批判や比較そのものは問題ない。

## 9. 判断しないこと

運営事務局は次を見本誌で判断しない。スキルもこれらを判定・指摘しない（ユーザーに聞かれた場合は「運営は判断しない項目なので、自己責任での判断になる」と伝える）。

1. 模倣や二次創作の表現（例: 表紙に有名ゲームのキャラクター、有名技術書シリーズに酷似した表紙）
2. 著作権やその背後関係（例: 他書からの一部転載、他者の発言を自分のもののように記載）
3. 技術的な正しさ（例: 動かないコード、誤った解説）
4. 本以外のデータ形式（ゲームの実行ファイル、動画・音声など）。ただし懸念があれば運営が個別に確認する場合がある
5. それが技術かどうか（ただし明らかに技術の流布が目的でない場合を除く）

「知的財産権の**著しい**侵害」は確認項目に含まれる。そのため、他書の大部分の丸写しのような明白なケースだけを ⚠️ で挙げ、それ以上の権利判断はしない。

## 10. 判断のしかたと書き方

**判断の基準**

- 技術解説の文脈で、概念・仕組み・防御策を説明しているものは問題としない。
- 次のような場合に指摘する。
  - 実害につながる具体的な手順・分量・入手方法などに踏み込んでいる
  - 違法行為・悪用を促す、推奨する、肯定する書きぶりになっている
  - 本筋と関係のない性表現・暴力表現が入っている
- 程度で段階を分ける。
  - ❌ 頒布不可と考えられる: 公式の禁止例に明らかに当たる
  - ⚠️ 要確認: 判断が分かれうる、表現の調整や注意書きで解消できる可能性がある
  - 危険性のある技術の本は、5の「判定の基準」の表を優先する
  - 指摘なし: 問題が見当たらない

**レポートの書き方**

- ページ番号、カテゴリ、問題と考える理由、修正案の方向性を書く。
- **本に載っている第三者の個人情報は書き写さない。** 個人情報の掲載を指摘するときは、ページ番号と種類（氏名、住所、アカウント名など）だけを書く。
- **問題箇所の危険な内容そのものは引用・要約しない。**「p.42: 特定の薬物の合成手順に具体的に踏み込んでいる」のように、何が問題かが伝わる粒度にとどめる。著者は自分の本なので、場所と理由が分かれば十分に修正できる。
- 指摘がない場合も「確認した範囲で問題は見当たらなかった」と書き、確認した範囲（全ページか一部か）と、画像は判定していないことを明記する。
